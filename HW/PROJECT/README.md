Анализ данных многопрофильных клиник: обработка и кластеризация

Данный проект посвящен исследованию набора данных о приемах в многопрофильных клиниках. Целью является предобработка данных, выявление аномалий и сравнение различных методов кластеризации для выделения групп пациентов/приемов на основе ключевых признаков.

Используется датасет с Kaggle: Multi-Location Healthcare Clinic Revenue Dataset.
Он содержит три таблицы: patients.csv, clinics.csv, appointments.csv. В работе основное внимание уделено файлу appointments.csv, который включает информацию о приемах: дата, специальность врача, ожидаемая и фактическая выручка, флаги отмен и неявок и др.

 Используемые библиотеки

· pandas, numpy – обработка данных
· matplotlib, seaborn – визуализация
· scikit-learn – предобработка, кластеризация, метрики
· scipy – статистические методы (z-score)
· google.colab – интеграция с Google Colab (загрузка kaggle.json)

Этапы работы

1. Загрузка и первичный анализ

· Загрузка данных через Kaggle API (требуется файл kaggle.json).
· Исследование структуры, пропусков, типов данных.
· Визуализация распределений числовых и категориальных признаков, корреляционная матрица.

2. Предобработка

· Обработка выбросов: каппинг (ограничение) по методу межквартильного размаха (IQR) для числовых признаков.
· Кодирование категориальных признаков: One-Hot Encoding (с удалением первого уровня для избежания мультиколлинеарности).
· Масштабирование: стандартизация числовых признаков (StandardScaler).
· Удаление неинформативных колонок (patient_id, doctor_id, clinic_id и др.).

3. Анализ аномалий

Для поиска аномальных записей применены следующие методы:

· Правила на основе IQR для каждого числового признака.
· Z-score (порог 3).
· Isolation Forest (contamination=0.05).
· Local Outlier Factor (LOF) (n_neighbors=50, contamination=0.05).

Для каждого метода подсчитано количество найденных аномалий, построены диаграммы рассеяния в пространстве главных компонент (PCA). Также вычислены пересечения методов и сформирован консенсусный флаг аномалии .

4. Кластеризация

Кластеризация проводилась по двум основным признакам: revenue_expected и revenue_realized (после масштабирования). Сравнивались следующие алгоритмы:

· K-Means – с определением оптимального числа кластеров методом локтя и силуэтным анализом.
· Иерархическая кластеризация (Agglomerative) – построена дендрограмма на подвыборке.
· DBSCAN – выбор eps по графику k-расстояний.
· Gaussian Mixture Model (GMM) – выбор числа компонент по BIC/AIC.
· OPTICS – автоматическое выделение кластеров на основе плотности.

Для каждого метода рассчитаны метрики качества:

· Силуэт (чем выше, тем лучше)
· Калински-Харабас (чем выше, тем лучше)
· Дэвис-Болдин (чем ниже, тем лучше)
· Интегральная нормализованная оценка на основе трёх метрик.

Построены визуализации кластеров в PCA-пространстве и столбчатые диаграммы сравнения метрик.

Результаты

· Лучший метод по интегральной оценке – K-Means (интегральная оценка 0.962).
· Худший – DBSCAN и OPTICS (интегральная оценка ~0.098).
· Аномалии наиболее уверенно выделяются методами Isolation Forest и LOF, но их пересечение невелико (253 записи из 1495–1497).
· Консенсусный подход (аномалия, если обнаружена хотя бы двумя методами) выявил 253 записи.


Примечание: при работе с OPTICS может появляться предупреждение RuntimeWarning: divide by zero encountered in divide. Это связано с внутренними вычислениями алгоритма и не влияет на результаты кластеризации. Предупреждение можно подавить, раскомментировав соответствующий блок кода.


 Заключение

Проект демонстрирует полный цикл анализа данных: от загрузки и очистки до применения методов машинного обучения для поиска аномалий и кластеризации. Полученные результаты позволяют лучше понять структуру данных и выделить группы пациентов/приемов, что может быть полезно для бизнес-аналитики и принятия решений.
