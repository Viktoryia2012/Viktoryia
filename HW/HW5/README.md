AI Worker Burnout and Attrition Risk Prediction

Данный проект посвящён анализу и прогнозированию уровня выгорания сотрудников и риска их увольнения с использованием методов машинного обучения. В работе сравниваются пять различных регрессионных моделей, выполняется подбор гиперпараметров для лучших из них, а также проводится визуализация результатов.

---

Цель проекта

· Загрузить и подготовить датасет о выгорании сотрудников, использующих ИИ.
· Обучить пять моделей регрессии: линейную регрессию, дерево решений, случайный лес, градиентный бустинг и метод опорных векторов (SVR).
· Сравнить модели по метрикам MSE, MAE и R².
· Выбрать лучшую модель и улучшить её с помощью подбора гиперпараметров.
· Визуализировать результаты, включая анализ важности признаков.

---

Датасет

Название: AI Worker Burnout and Attrition Risk Dataset
Источник: Kaggle (автор: Nudrat Abbas)

Датасет содержит информацию о 1500 сотрудниках, работающих с ИИ-инструментами. Для каждого сотрудника представлен 21 признак, включая:

· employee_id – уникальный идентификатор.
· job_role, education_level, country, industry, company_size и другие категориальные признаки.
· years_experience, team_size, salary_usd_k, ai_tools_used_per_day – числовые показатели.
· burnout_score – целевая переменная (уровень выгорания).
· attrition_risk – риск увольнения (использовался в качестве целевой после преобразования в числовой вид).

Целевая переменная: в данной работе выбрана колонка attrition_risk (риск увольнения), которая была преобразована из категорий (Low, Medium, High) в числовые значения (0, 1, 2). Задача регрессии – предсказать этот риск на основе остальных признаков.

---

Модели

Модель Краткое описание
Linear Regression Линейная модель, предполагающая линейную зависимость.
Decision Tree Дерево решений, нелинейная модель, склонна к переобучению.
Random Forest Ансамбль деревьев, усредняющий их прогнозы.
Gradient Boosting Последовательное построение деревьев, каждое исправляет ошибки предыдущего.
SVR Метод опорных векторов для регрессии с RBF-ядром.

Метрики оценки

· MSE (Mean Squared Error) – средний квадрат ошибки. Чем меньше, тем лучше.
· MAE (Mean Absolute Error) – средняя абсолютная ошибка. Чем меньше, тем лучше.
· R² (коэффициент детерминации) – доля дисперсии, объяснённая моделью. Чем ближе к 1, тем лучше.

Подбор гиперпараметров

Для градиентного бустинга была задана сетка:

· n_estimators: [150, 200]
· learning_rate: [0.05, 0.1]
· max_depth: [4, 5]
· min_samples_split: [2, 5]
· subsample: [0.8]

Поиск выполнялся с 5-кратной кросс‑валидацией по метрике R².

---

Результаты

Сравнение моделей

После обучения пяти базовых моделей и подбора гиперпараметров для градиентного бустинга были получены следующие результаты на тестовой выборке:

Модель MSE MAE R²
Gradient Boosting 0.0921 0.1981 0.7221
Gradient Boosting (tuned) 0.0932 0.1959 0.7186
Random Forest 0.0969 0.1669 0.7074
Linear Regression 0.1108 0.2713 0.6656
SVR 0.1118 0.2577 0.6625
Decision Tree 0.1900 0.1900 0.4265

Лучшая модель: Gradient Boosting с R² = 0.7221 (базовая версия без подбора дала незначительно лучший результат на тесте, что может быть связано с особенностями разбиения; tuned-версия показала близкие метрики).

Важность признаков

Анализ важности признаков для лучшей модели (Gradient Boosting) выявил наиболее влияющие факторы на риск увольнения:

1. fear_of_ai_replacement_High (страх замены ИИ – высокий): 0.382
2. job_satisfaction_1_5 (удовлетворённость работой): 0.379
3. burnout_score (уровень выгорания): 0.149
4. ai_replaces_my_tasks_pct (процент задач, заменяемых ИИ): 0.006
5. salary_usd_k (зарплата в тысячах долларов): 0.003

Остальные признаки вносят незначительный вклад (менее 0.003).

---

Выводы

1. Модели на основе ансамблей (Gradient Boosting и Random Forest) значительно превосходят линейную регрессию и одиночное дерево.
2. Наилучший результат показал градиентный бустинг (R² ≈ 0.72). Это говорит о том, что взаимосвязи между признаками и риском увольнения достаточно сложны и нелинейны.
3. Наиболее важными факторами оказались страх замены ИИ, удовлетворённость работой и уровень выгорания – это согласуется с бизнес‑гипотезами о причинах текучести кадров.
4. Подбор гиперпараметров не привёл к существенному улучшению на тестовой выборке, что может указывать на то, что базовая модель уже близка к оптимуму для данного набора данных.
5. Полученную модель можно использовать для предсказания риска увольнения новых сотрудников и для выявления зон риска в компании.
