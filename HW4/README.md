Классификация видов физической активности человека (Human Activity Recognition)

Данный проект посвящен задаче классификации видов физической активности на основе данных, собранных с акселерометров и гироскопов смартфонов. В работе сравниваются различные алгоритмы машинного обучения для предсказания одного из шести видов активности: ходьба, подъем по лестнице, спуск по лестнице, сидение, стояние, лежание.

Описание данных

Используется датасет Human Activity Recognition with Smartphones из репозитория UCI Machine Learning Repository.

· Источник данных: акселерометр и гироскоп смартфона Samsung Galaxy S II, закрепленного на поясе испытуемого.
· Выборка: 30 добровольцев в возрасте 19-48 лет.
· Признаки: 561 признак, включая статистические характеристики временных и частотных сигналов (средние значения, стандартные отклонения и др.).
· Целевая переменная: шесть классов активности:
  · WALKING – ходьба
  · WALKING_UPSTAIRS – подъем по лестнице
  · WALKING_DOWNSTAIRS – спуск по лестнице
  · SITTING – сидение
  · STANDING – стояние
  · LAYING – лежание
· Разделение: данные уже разбиты на обучающую (train.csv) и тестовую (test.csv) выборки.

Используемые модели

В рамках исследования были обучены и протестированы следующие модели:

1. Gradient Boosting (HistGradientBoostingClassifier) – реализация градиентного бустинга от scikit-learn.
2. K-ближайших соседей (KNN) – метод, основанный на близости объектов в пространстве признаков.
3. Decision Tree – решающее дерево.
4. XGBoost – популярная библиотека градиентного бустинга.
5. Random Forest – ансамбль решающих деревьев.
6. Linear SVM (LinearSVC) – линейная SVM с регуляризацией.

Для каждой модели проводился подбор гиперпараметров с помощью кросс-валидации (GridSearchCV / RandomizedSearchCV). Признаки масштабировались с помощью StandardScaler.

Результаты

Сравнение моделей проводилось на тестовой выборке по метрикам: точность (accuracy), полнота (recall), precision и F1-мера (в макро-усреднении).

KNN 0.9801 0.9800 0.9800 0.9800
Decision Tree 0.9343 0.9331 0.9331 0.9327
XGBoost 0.9413 0.9431 0.9399 0.9408
Random Forest 0.9226 0.9235 0.9196 0.9208
Linear SVM 0.9586 0.9633 0.9590 0.9600

Лучшей моделью оказался KNN с параметрами:

· n_neighbors = 3
· p = 1 (манхэттенское расстояние)
· weights = distance

Точность на тестовой выборке достигла 98.01%.

Матрицы ошибок и отчеты по классификации для каждой модели представлены в ноутбуке. KNN показал отличные результаты для всех классов, особенно хорошо разделяя статические позы (сидение, стояние, лежание). Линейная SVM также продемонстрировала высокое качество (95.86%).

Выводы

1. KNN с метрикой Манхэттена и взвешиванием по расстоянию оказался наиболее точным для данной задачи, что может быть связано с характером данных (высокоразмерное пространство, но локальные структуры хорошо разделяют классы).
2. Ансамблевые методы (Random Forest, Gradient Boosting) показали несколько худшие результаты, что, вероятно, объясняется тем, что признаки уже достаточно информативны и не требуют сложных нелинейных комбинаций.
3. Линейная SVM показала хороший баланс между точностью и интерпретируемостью.
4. Наибольшие ошибки модели допускали при различении сидения и стояния, что ожидаемо, так как эти активности имеют схожие сигналы.

Требования для запуска

· Python 3.8+
· Установленные библиотеки:
  ```
  numpy
  pandas
  matplotlib
  seaborn
  scikit-learn
  xgboost
  joblib
  ```
· Датасет должен быть загружен и расположен в папке human-activity-recognition-with-smartphones/ (файлы train.csv и test.csv). Либо можно использовать скрипт из ноутбука для автоматической загрузки через Kaggle API.

Инструкция по запуску

1. Клонировать репозиторий или скачать файл HW4 (4).ipynb.
2. Установить зависимости: pip install -r requirements.txt (или установить вручную библиотеки из списка выше).
3. Загрузить датасет с Kaggle и разместить CSV-файлы в указанной директории (либо настроить путь).
4. Открыть ноутбук в Jupyter Notebook / Google Colab и выполнить последовательно все ячейки.
5. После обучения модели сохраняются в файлы best_*.pkl.
